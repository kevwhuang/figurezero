# Figure Zero Project

Three-page marketing site for the Figure Zero Project, a student-run organization pairing artists and writers with scientific journals to create original cover illustrations. Features a letter-animated hero, hand-drawn doodle accents, testimonies, team roster and cover gallery backed by content collections, and a persisted light and dark theme. Built with Astro, TypeScript, Tailwind CSS, and GSAP. Deployed on Netlify.
